# Contributing

This project is in early alpha. We're looking for feedback more than code right now.

## How to help

The most valuable contributions at this stage are experience reports:

1. **Try to install it.** Did the instructions in README.md actually work? If not, open an issue describing where you got stuck and what OS/Python version you're on.

2. **Use it for a real task.** Pull permits for a property you're evaluating, run comparables for a neighborhood you know, generate a market context report. Tell us what was useful and what was missing.

3. **Tell us what broke.** Empty results, confusing output, API errors — all useful. Open an issue with the query you tried and what happened.

## Opening issues

Use the issue tracker for bugs, feature requests, and experience reports. A good issue includes:

- What you tried to do
- What happened (or didn't)
- Your setup (OS, Python version, Claude Desktop version)

## Code contributions

We're not yet accepting large code contributions — the architecture is still settling. Small fixes (typos, documentation improvements, error message clarity) are welcome as PRs.

If you're interested in building a data adapter for another city, open an issue first so we can discuss the interface design.

## Code of conduct

Be kind. Be constructive. Remember that this started as one person's side project and is maintained part-time.
