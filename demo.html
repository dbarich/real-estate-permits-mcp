Real Estate Permits MCP Prototype

An AI-native interface to Seattle's building permit and property data

The Problem

Small-scale real estate developers building 2-8 unit projects make critical financial decisions — site acquisition, construction loan applications, feasibility studies — using fragmented municipal data scattered across multiple government portals.

Today that means manually searching Seattle's SDCI portal for permits, cross-referencing the King County Assessor for property values, and compiling everything into spreadsheets. A single market research pull takes 2-4 hours. Professional consultant reports cost $2K-$5K.

This server turns that into a conversation.

Architecture

The MCP server sits between Claude and two public data APIs. You ask questions in natural language. Claude calls the right tools. The server queries the APIs and returns structured results.

What a Conversation Looks Like

Here are real queries this server handles:

Permit Search

You
What permits have been issued on Dearborn St in the last year?
Claude (via MCP)
Found 12 permits on Dearborn St. 3 are new construction (including a 4-unit stacked dwelling at 2412 S Dearborn), 5 are alterations, and 4 are mechanical. The new construction permits range from $380K to $1.2M in estimated value...

Property Lookup

You
What's the parcel info for 2412 S Dearborn St?
Claude (via MCP)
PIN: 6362900036. Zoned LR1(M). Lot size: 5,000 sq ft. Present use: Single Family Residence. Appraised value: $249,000 (land) + $189,000 (improvements). Last sale: 2023 at $249,000...

Development Comparables

You
Show me development comparables near 2412 S Dearborn for my bank loan application.
Claude (via MCP)
I'll pull both permit activity and property data for the Dearborn corridor. [Calls get_development_comparables] Here's what I found: 4 active construction permits within 2 blocks, nearby parcels assessed at $245K-$680K, and 3 recent sales showing an upward trend...

Validated Use Case: Bank Underwriting

This server was built to support a real construction loan application for a 4-level stacked dwelling unit project in Seattle's Judkins Park neighborhood.

The workflow:

  1. Developer asks Claude for market context around their target site
  2. MCP server pulls permit activity, comparable properties, and recent sales
  3. Claude synthesizes the data into a narrative with supporting numbers
  4. Output feeds directly into a bank underwriting document

What previously took 2-4 hours now takes about 5 minutes.

The data comes from the same public sources a consultant would use. The difference is that the queries are repeatable, composable, and conversational — you can ask follow-up questions, adjust parameters, and drill down without starting over.

Try It Yourself

Prerequisites

Python 3.10+ and Claude Desktop (or any MCP-compatible host).

Install (30 seconds)

pip install mcp httpx

Configure Claude Desktop

Add this to your claude_desktop_config.json:

{
  "mcpServers": {
    "seattle-permits": {
      "command": "python",
      "args": ["/path/to/src/seattle_permits_server.py"]
    }
  }
}

Restart Claude Desktop. The 8 tools appear automatically.

First query to try

"What multifamily permits have been filed in 98144 in the last 6 months?"

No API keys. No database. No server to maintain. Just a Python script and a config entry.
